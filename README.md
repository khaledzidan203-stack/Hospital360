# Hospital 360

End-to-end hospital financial, operational, administrative, and technology performance analytics project.

Planned stack:

- Python
- PostgreSQL
- SQL
- Power BI
- Git / GitHub

Project Status: Initial Setup

## Enterprise Performance Extension

Hospital360 includes a validated 36-month synthetic enterprise extension for Finance, Workforce, Operations, and Technology. It adds deterministic generation, PostgreSQL RAW/STAGING/ANALYTICS layers, read-only SQL analysis, reproducible Python EDA, and four Power BI pages. The accepted enterprise snapshot contains 25,716 fact rows from 2023-08-01 through 2026-07-31.

All enterprise records are synthetic portfolio data. They do not represent real patients, employees, hospital financial statements, or production technology operations. Existing Synthea claim activity remains analytically separate from the new synthetic hospital finance facts.
