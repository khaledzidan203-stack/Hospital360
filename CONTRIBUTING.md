# Contributing to Hospital360

1. Fork the repository and create a focused feature branch.
2. Make small, clearly described commits.
3. Run the relevant tests, reconciliation checks, and report validation before proposing changes.
4. Use synthetic data only; never contribute real patient, employee, customer, or confidential company data.
5. Never commit credentials, `.env`, large RAW datasets, PBIX binaries, caches, or logs.
6. Preserve fact grains and document changes to KPIs, DAX, relationships, data-quality rules, or generation assumptions.
7. Include concise documentation and representative tests for new behavior.
