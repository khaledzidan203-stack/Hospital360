# Hospital360 Navigation Standard

1. The Home page is the report index.
2. Each active Home tile uses a native transparent button overlay: **Action = On**, **Type = Page navigation**, **Destination = target report page**.
3. Every analytical page includes the native Home icon/button in the top-left position.
4. The page Home icon uses **Action = On**, **Type = Page navigation**, **Destination = Home**.
5. Power BI Desktop navigation uses **CTRL + CLICK**; Power BI Service and reading mode use a single click.
6. Use the same Home icon design and location established on Executive Overview.
7. Navigation controls must not display visual headers.
8. Update the Home navigation grid whenever a future analytical page becomes active.
9. Every page reuses the established page background, header style, footer, containers, and border styling.

## Home Button

- Use a clearly recognizable house/Home icon in the standard top-left location.
- Use **Page navigation → Home**.
- Use the tooltip **"Ctrl + Click to return to Home"**.
- Power BI Desktop navigation uses **CTRL + CLICK**.
- Reading and published modes use a normal single click.
- Every future analytical page must reuse this exact Home button style and tooltip.
